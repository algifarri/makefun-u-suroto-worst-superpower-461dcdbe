Entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on make.fun: invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can fold a fitted sheet perfectly — but only in my dreams, and I forget how the second I wake up.

99 characters. A superpower that only works while asleep, and whose one skill evaporates the moment it could ever be used.

## How it works

`main.py` (Python 3, standard library only) writes that single line to `/output/entry.txt`. Deterministic: the same bytes on every run. Verified locally: the output is exactly 99 characters / 101 bytes, inside the 1–140 character gate.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
